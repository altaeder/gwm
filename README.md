# GalleryWM
-----

GalleryWM is a wayland based compositor, built to challenge the desktop metaphor. Forked from hevel, and incorporating features from both this and other projects, including: Neuwm.

Experimental software, not in any stable release state. Repos are mainly for proper version control and ease of access while im developing this. If anyone gets something else out of this tho, i consider that a nice bonus.

shoutout to the og of infinite scrolling canvas compositors, Hevel:

Whose brilliant idea sent me on this months long rabbit hole.
